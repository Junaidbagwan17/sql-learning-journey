# 📘 Basic SQL | Data Analyst Learning Path

Welcome to my Basic SQL learning journey!

This section covers the fundamental SQL concepts required to work with databases, retrieve data, clean and filter records, and perform basic business analysis.

My goal is to develop strong SQL skills for an entry-level **Data Analyst role** using MySQL.

## 🎯 Learning Objectives

By completing this section, I aim to:

- Understand relational databases and SQL fundamentals.
- Retrieve data from database tables.
- Filter, sort and manipulate query results.
- Perform calculations using SQL functions.
- Summarise data using aggregate functions.
- Analyse business data using GROUP BY and HAVING.
- Create conditional classifications using CASE WHEN.
- Solve real-world business questions independently.
